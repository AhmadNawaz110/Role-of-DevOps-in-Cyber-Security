Code Example · GitHub Actions

Secure CI/CD Pipeline

.github/workflows/secure-ci.yml
SECURE
name: Secure CI/CD Pipeline

on:
  push:
    branches: [main]
  pull_request:

# Least-privilege permissions — no wildcard
permissions:
  contents: read
  security-events: write
  id-token: write   # OIDC for keyless auth

jobs:
  security-scan:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0    # full history for secret scan

      # 1. Secret scanning
      - name: Scan for secrets
        uses: gitleaks/gitleaks-action@v2
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      # 2. SAST with CodeQL
      - name: CodeQL Analysis
        uses: github/codeql-action/init@v3
        with:
          languages: javascript, python
          queries: security-extended

      - run: npm ci && npm run build
      - uses: github/codeql-action/analyze@v3

      # 3. SCA — dependency review on PRs
      - name: Dependency Review
        if: github.event_name == 'pull_request'
        uses: actions/dependency-review-action@v4
        with:
          fail-on-severity: high

      # 4. Container build + scan
      - name: Build & Scan Image
        uses: aquasecurity/trivy-action@master
        with:
          image-ref: app:${{ github.sha }}
          format: sarif
          exit-code: 1
          severity: CRITICAL,HIGH
          ignore-unfixed: true

      # 5. Generate SBOM
      - name: Generate SBOM
        uses: anchore/sbom-action@v0
        with:
          artifact-name: sbom.spdx.json

      # 6. Sign with Cosign (keyless via OIDC)
      - name: Sign image
        uses: sigstore/cosign-installer@v3
      - run: cosign sign --yes app:${{ github.sha }}
SECURE PATTERNS
✓ Explicit permissions (no write-all)
✓ OIDC keyless authentication
✓ Fail-on-severity thresholds
✓ SBOM generation per build
✓ Cosign artifact signing
✓ SARIF upload to GitHub Security
COMMON PITFALLS
✗ Using ${{ secrets.GITHUB_TOKEN }} in scripts (injection)
✗ pull_request_target on untrusted PRs
✗ Self-hosted runners without isolation
✗ No timeout-minutes (DoS)
Code Example · Dockerfile

Dockerfile: Insecure vs Secure

INSECURE
Dockerfile.bad
FROM ubuntu:latest

# Running as root
RUN apt-get update && apt-get install -y \
    python3 python3-pip curl

# Secret baked into image
ENV AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
ENV AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG

# Copy entire source with secrets
COPY . /app
WORKDIR /app

# Expose everything
EXPOSE 8080

# Latest tag, no health, no labels
CMD ["python3", "app.py"]
✗ Runs as root
✗ Hardcoded AWS credentials
✗ :latest tag (non-reproducible)
✗ No image label / SBOM
✗ Full source copied (incl .git)
SECURE
Dockerfile.secure
# Pin digest for reproducibility
FROM python:3.12-slim@sha256:abc123... AS builder

# Non-root user from start
RUN groupadd -r app && useradd -r -g app app

# Install as root, switch later
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Multi-stage: only copy what's needed
FROM python:3.12-slim@sha256:abc123...
RUN groupadd -r app && useradd -r -g app app
COPY --from=builder /usr/local/lib/python3.12 \
                  /usr/local/lib/python3.12
COPY --chown=app:app app/ /app/
WORKDIR /app

# Drop privileges
USER app

# Read-only filesystem
HEALTHCHECK --interval=30s --timeout=3s \
  CMD curl -f http://localhost:8080/health || exit 1

# OCI labels for provenance
LABEL org.opencontainers.image.source="https://github.com/org/app"
LABEL org.opencontainers.image.revision="${GIT_SHA}"

EXPOSE 8080
CMD ["python3", "app.py"]
✓ Pinned image digest
✓ Non-root USER
✓ Multi-stage build (smaller surface)
✓ HEALTHCHECK defined
✓ OCI labels for traceability
